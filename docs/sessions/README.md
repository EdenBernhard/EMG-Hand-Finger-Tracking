# Session-Protokolle

Eine Datei pro Arbeitstag (`JJJJ-MM-TT.md`), erzeugt mit `/protokoll` in Claude Code.

Die Notizen sind Primärquellen für die wissenschaftliche Arbeit. Sie werden nur ergänzt, nie nachträglich umgeschrieben.
Das fortlaufende Forschungslogbuch (Claude-Doc) wird aus diesen Notizen und den diktierten Erkenntnissen zusammengeführt.
